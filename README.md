# GTA Co-op — versões

Pacotes de instalação do **GTA Co-op**, um mod de co-op para o modo história do GTA V Enhanced (PC).
Este repositório só tem as versões publicadas (o `atualizar.bat` do mod lê daqui).

- `ultima.json`: a versão atual (nome do pacote, SHA-256, data, novidades).
- `pacotes/`: os `.zip` de cada versão.

## Instalar

Baixe o `.zip` mais novo em `pacotes/` e siga o `LEIA-ME.md` que vem dentro dele.
Você também precisa do **ScriptHookV** (baixe em dev-c.com; ele não pode ser redistribuído).

## Atualizar

Com o jogo fechado, rode `gtacoop\ferramentas\atualizar.bat` (na pasta do jogo).

**Nunca entre no GTA Online com mods instalados.**

O pacote inclui o ScriptHookVDotNet Enhanced (github.com/Chiheb-Bacha), com as licenças dele em `licencas/`.
